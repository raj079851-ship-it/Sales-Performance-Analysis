# 📊 Sales Performance Analysis

An end-to-end **Sales Performance Analysis** project using the **Superstore dataset** to analyze sales, revenue, profit, product performance, category trends, and regional performance. The project combines **Python, SQL, PostgreSQL, and Power BI** to transform raw sales data into actionable business insights.

---

## 🚀 Project Overview

The objective of this project is to understand overall sales performance and identify the key factors influencing **sales and profitability**.

The analysis covers:

* Sales and revenue performance
* Profitability analysis
* Product and category performance
* Regional performance
* Sales trends over time
* Top and underperforming products
* Business insights using SQL
* Interactive dashboard development using Power BI

The project follows a complete data analytics workflow from **data preparation to business intelligence reporting**.

---

## 🗂️ Dataset

The project uses the **Superstore dataset**, a commonly used retail sales dataset containing transactional information about orders, customers, products, sales, discounts, and regions.

### Key Data Fields

The dataset includes information such as:

* Order Date
* Ship Date
* Customer
* Customer Segment
* Product
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit
* Region
* State
* City
* Postal Code

A derived **Profit** column (With Profit Margin 10%) is also used for profitability analysis where required.
